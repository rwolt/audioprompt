# AudioPrompt

**[English README → README.md](README.md)**

AI音楽ツールを誘導するための、短い「オーディオプロンプト」を生成します。AudioPromptは、スケールに沿ったメロディをピンクノイズにインプリントし、MIDIファイルからドラム・ベースレイヤーを追加し、ボーカル／ギター／ベースの周波数帯域を強調し、アップロード用にプロンプトをトラックの先頭に連結できます。

**ライブデモ:** [https://audioprompt.streamlit.app/](https://audioprompt.streamlit.app/)

📖 **アプリの詳細マニュアル**（全コントロールの説明、MIDIドラムマップ、DSPの仕組み・英語）: [`audioprompt_app/README.md`](audioprompt_app/README.md)

## ✨ 主な機能

- 🧠 スケール駆動のメロディインプリント — スケール内のランダムメロディ、ビブラート／グライド、音色プリセット付き
- 🥁 **ドラムMIDIインプリント** — General MIDIドラムトラックからベロシティ対応のリズムノイズレイヤーを生成
- 🎸 **ベースMIDIインプリント** — ピッチベンドとベロシティを保持したベースMIDIから連続的なベースレイヤーを生成
- 🎚️ スペクトルフォーカス（ボーカル／ギター／ベースのプリセット、またはカスタムHz帯域）とリズミックゲート
- 🗣️ **母音インプリント** — 歌唱母音のフォルマント整形（英語・日本語・スペイン語のプリセット）
- 🌏 **UIは英語と日本語に対応** — ブラウザの言語設定から自動検出、いつでも切り替え可能
- ♿ **ヘルプのテキスト表示** — すべての説明をホバー式ツールチップではなく読めるテキストとして表示するアクセシビリティモード
- 📎 ドラッグ＆ドロップ入力、タグ付きWAVダウンロード、Pure PythonのDSP（NumPy/SciPy/soundfile）

## 🚀 アプリの実行

```bash
cd audioprompt_app
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

使い方: 音声をドロップ（任意）→ メロディ／ドラム／ベースレイヤーを設定 → **プロンプトを生成** を押す → タグ付きWAVをダウンロード。3〜6秒のプロンプトがマスキングなしで明確に誘導できます。

## 🌏 言語とアクセシビリティ

- UIは**英語**と**日本語**に対応。初回訪問時にブラウザの言語を自動検出し、ページ上部のセレクターでいつでも切り替えられます。`?lang=ja` / `?lang=en` で直接リンクも可能です。
- **「ヘルプをテキストで表示」**（ページ上部、または `?help=text`）を有効にすると、各コントロールの説明がホバー式ツールチップではなくコントロールの下にテキストとして表示されます。スクリーンリーダー使用時に推奨です。
- 日本語訳は機械翻訳をベースに音楽制作用語を調整したものです。**ネイティブスピーカーによる訳文の改善提案を歓迎します**（全文字列は [`audioprompt_app/ui_strings.py`](audioprompt_app/ui_strings.py) にあります）。

## 🗣️ 母音インプリントについて（日本語プリセット）

「母音キャラクター」で日本語を選ぶと、「あ・い・う・え・お」の5母音をすべてのノートにインプリントします（日本語はモーラ拍のため母音の弱化はありません。「う」は非円唇の明るい日本語のウを使用）。これは緩やかな音響的バイアスであり、歌詞を歌わせる機能ではありません — 言語や歌詞への影響は、AIツール側のテキストプロンプトの方がはるかに大きい点にご注意ください。

## 📄 プライバシー

- 音声の権利はすべてユーザーに帰属します。アップロードされたファイルはプロンプト生成の目的でのみ処理されます。
- 本アプリはアップロードされた音声やユーザーデータを保存しません。デフォルトでは一切の分析データを収集しません — ご自身で実行する場合（ローカル／セルフホスト）、環境変数 `GOATCOUNTER_URL` を設定しない限り、何も追跡されず外部送信もありません。
- 公開デモは `GOATCOUNTER_URL` を設定し、プライバシーに配慮した [GoatCounter](https://www.goatcounter.com/) で集計分析（ページビューとリファラーのみ）を行っています。Cookieなし、個人データなし、個人・クロスサイト追跡なし。
